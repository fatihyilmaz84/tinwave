T-0011 native popup probes, Qt 6.12.0 MSVC, Windows 11 build 26200 (dark OS mode, Dutch UI language), 150 % scaling.
Method: host opens the popup, enumerates the visible top-level windows of its OWN process (EnumWindows by PID),
records Win32 class/title/size, crops a screenshot of just that window, then dismisses it (EndMenu / WM_CLOSE).
Probe command: t0011-host.exe --style <S> --probe menu|file|folder|message [--dark-menus N] --probe-shots <dir>

         content check: MenuItem text, MenuSeparator, checkable item (check mark), disabled item, submenu arrow all native.
