Quiet Native

The desktop design system for Tinwave. The operating system draws the chrome and the controls; the artwork brings the color; Tinwave adds only what music needs.

v0.1 · ADR 0003 Qt 6.8 LTS · Qt Quick Controls native styles Windows · macOS · Linux

Accent = the OS accent Read from palette.accent (Qt 6.6+). The user can pin Tin Teal instead. Contrast is checked at runtime; if the OS accent fails 4.5:1 on the surface, text uses accentText, a darkened (light) or lightened (dark) step.
Artwork carries color Chrome stays neutral. No tinting the window from cover art, no gradients behind content. Now Playing may sample one muted tone from the cover for its backdrop at ≤ 8 % opacity.
Meaning never by hue alone Source, tier and status colors always travel with an icon and a word. Server (blue) and Downloaded (green) also differ in lightness and glyph.
