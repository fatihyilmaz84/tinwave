SPIKE RESULT T-0011
answer: Confirm ADR 0003 for Windows (FluentWinUI3, native dialogs, Mica) with four amendments: (A1) select the style explicitly, because Qt 6.12's default Windows style has no dark mode; (A2) native Win32 menus draw light in a dark OS unless the process calls the undocumented uxtheme SetPreferredAppMode, otherwise use Popup.Window; (A3) Mica needs QT_QPA_DISABLE_REDIRECTION_SURFACE=1 or the sidebar renders white; (A4) MessageDialog is a Qt Quick window on Windows and Linux, not native. Also fix several design-system §3 token bugs. Keep Qt 6.8 provisionally; it was not run (only 6.12 installed).
confidence: medium (high for Windows/Qt 6.12 measurements; low for Qt 6.8 behaviour, macOS, Linux and real OS setting changes, all unverified)
